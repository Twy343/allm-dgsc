# 干预方法索引

报告分类说明见 [SC干预方法分类](../../docs/INTERVENTION_TAXONOMY.md)。

- operator_families.csv：4类基本操作及实际应用区域。
- semantic_regions.csv：本样本语义区域与位置，不增加方法种类数。
- design_axes.csv：通道、内容、范围、时间、幅度等设计维度。
- condition_method_map.csv：166种操作序列映射，其中162个完成的扰动配置、1个baseline、3个中途前缀。
- classification_summary.json：去重口径；多操作组合的覆盖数不可相加。

代表现象、匹配对照和逐步证据见[中期结果存档](../interim_sc_case_study/README.md)。
