# SC 干预方法分类

本表用于报告第一方向的方法部分。此前的“162个不同扰动”应写成
**162个已完成的扰动配置**。它们由4类基本操作组成；位置、范围、步数、强度和
持续轮数是设计变量，不能各自计成新的扰动方法。

## 与 transparency 论文的对应

来源：[How Transparent is DiffusionGemma?](https://arxiv.org/html/2606.20560v1)。
第3.1节研究瓶颈消融，第3.2节分类候选与最终token的关系，第5节按生成现象组织个例。
跨去噪步的activation patching出现在第7.2节的研究建议中。

据此，下面将我们自己的**操作定义、实验设计、结果现象**分别整理；这不是论文原有的
四类扰动清单，也不把我们的人工分布替换称为已完成的跨样本activation patching。

## 一 基本操作

| ID | 方法 | 实际改动与保持项 | 已做的对象和范围 | 主要问题 |
| --- | --- | --- | --- | --- |
| O1 | 候选logits交换 | 在选定SC行交换候选a、b的shaped logits；整行概率值集合、总质量与entropy不变，候选身份改变。 | MBPP277比较符号；value/v的单个或多个关联位置；参数n/threshold。GSM480中间数字2/4。 | 保持不确定性时，改变候选身份是否影响下一轮及相关位置？ |
| O2 | SC分布替换或混合 | 令p'=(1-alpha)p+alpha*q，再用原生编码器生成SC。alpha=1是完全替换；0<alpha<1是部分注入。entropy可能改变。 | 单个比较符号；一致变量命名；参数及引用；整段return表达式模板；GSM算式模板及无关模板。 | 人工指定的内容是否被采用、传播、修复，是否影响置信度与停止？ |
| O3 | SC清零消融 | 直接将选定反馈embedding行设为0。不是把logits设0，也不是令概率均匀。 | MBPP277目标行、整个256位置、仅保留目标行；GSM331目标行、附近16位置、整canvas。 | 有用信息来自目标本身、邻域还是更广泛的SC？ |
| O4 | 当前canvas token替换 | 在下一次forward之前改C中的token，SC由独立设计决定是否改动；不把人工编辑标成模型accepted。 | 比较符号、变量绑定/引用、参数名、注释。 | 当前可见文本与SC分别提供什么信息，相互一致或冲突时如何响应？ |

本轮O2的q主要为指定单token的点质量；区域模板是一行指定一个token。
O2中的区域模板是同一种分布编辑对一组位置的应用，**不另算第5类方法**。
连续区域和离散关联位置也分开标注，不能都称“区域平移”。
O1和O2操作的是已经温度整形的logits/概率，不再次除温度。
理论保持量以实际dtype舍入为准；原记录保留了分布误差和SC embedding改变量。

## 二 在哪些语义区域上操作

以下是固定原batch4、seed100008的MBPP277轨迹，位置采用0基索引。
原函数为 `dict_filter(d,n)`，核心表达式为
`return {key: value for key, value in d.items() if value >= n}`。
这些位置用于描述本样本的语义对象，不构成额外的方法种类。

| 区域 | 位置 | 已做操作及内容 |
| --- | --- | --- |
| 决策符号 | 58 | O1/O2/O4；>=与<、<=、>、==、!=的对照，单独或联合修改。 |
| 值变量及其引用 | 46、50、57 | O1/O2/O4；return值、循环绑定、条件左侧；分别编辑或一致改为v/x/val/n等。 |
| 键变量及其引用 | 44、48 | O2/O4；与值变量一起编辑为k/v，或观察未编辑的键位置是否随之变化。 |
| 阈值参数及引用 | 14、59 | O1/O2/O4；n与threshold；单独修改可能造成悬空引用，一致修改检验绑定协调。 |
| 描述性文字对照 | 35 | O2/O4；docstring中的n改为threshold，与参数/条件位置比较；测得相同embedding扰动幅度。 |
| 完整返回表达式 | 42至60，连续19位置 | O2模板；原内容、一致k/v命名、错误比较符号或n绑定。模板来自已知原轨迹/人工构造，不能用来声称生成效率。 |
| 注释对照 | 63 | O4；将注释中的Test改为#，观察额外去噪机会。它也改变forward输入，不是直接关闭停止器。 |
| 全局及补集 | 0至255；或除58以外的位置 | O3；全清零、仅保留目标原SC、仅保留目标的指定分布。 |

GSM480中，目标算式区域97至104为 `4 \\div 2 = 2`；做过单点2/4交换、
一致反事实 `8 \\div 2 = 4` 模板和无关模板。GSM331做过单行/邻域/全局消融。
相同基本操作用于不同区域时，记录为覆盖范围，而非新的方法。

## 三 独立列出的设计变量

| 设计轴 | 本轮取值或对照 | 计数方式 |
| --- | --- | --- |
| 通道 | SC-only、canvas-only、joint | joint是基本操作的组合，不是新原子操作。 |
| 内容关系 | 原内容、等价改名、错误算符、绑定冲突、一致修复、无关内容 | 区分语法改变、程序语义改变与等价表达。 |
| 空间支持 | 单点、离散关联位置、连续表达式、邻域、全局、目标补集 | 位置集合是参数，不计成方法。 |
| 时间 | 完成step2/3/4后的编辑；单次或连续脉冲 | 不同时间和重复次数是配置。 |
| 接受状态 | 接受前/接受后 | 必须查目标位置的mask；同一步不同字段可能状态不同。 |
| 幅度 | 分布混合alpha、交换实际移动的概率、SC embedding变化 | alpha不是支路缩放beta；相同alpha不保证相同向量改变量。 |
| 观测范围 | 后续1/3/5步、直到本canvas自然停止 | 同一分支的不同快照不是新方法或独立重复。 |

一致/冲突指预设修改内容的关系，不保证混合后的SC最高概率一定已转向目标。
单点或区域的“接受后”都指实际mask，不是永久commit。若整样本已停止，另行处理重开，
不能把在原断点恢复与重开已停止样本混为一谈。

## 四 按结果现象展示个例

方法表回答“做了什么”；结果表单独回答“发生什么”。同一种方法可以产生不同结果。

| 现象 | 本轮代表例 | 判读 |
| --- | --- | --- |
| 内容协调 | O1/O2修改value/v，相关引用一致重命名；部分未编辑key也改变 | 等价程序内容选择及跨位置影响，不能单独称为算术推理改变。 |
| 暂时采用后修复 | O2+O4将>=改为>；step5真实接受>，step6恢复>= | 此处step5模型argmax仍为>=；实际采样与argmax必须分开。 |
| 停止时错误保留 | 联合改为<=或==，或形成n>=n绑定错误 | 分别记录本canvas函数测试；不声称完整多canvas回答已评分。 |
| 再加噪与停止交互 | 三处SC向v混合alpha=.70/.75，部分位置重新加噪而同轮停止 | 区分候选分布、选择mask、实际输出与全局停止，不能只看最终文字。 |
| 恢复或无效 | 单个错误符号的许多SC-only分支恢复正确比较；GSM数字反事实未被采用 | 同样保留。未改变最终答案不等于轨迹完全无影响。 |

这些是我们的结果分类。报告展示建议为“操作定义—语义区域—匹配对照—逐步响应—结果”，
而不是依次展示162个参数组合。要用原始概率与语义span对齐确认，避免把排版位移当成数字改错。

## 五 与此前baseline的边界

原有top-k/threshold属于信息瓶颈检查：按规则保留候选，摊平其余尾部，保持保留候选的
概率；与O2主动注入指定内容不同。其参考是原文第3.1节及附录C。
原有post-MLP beta=.1属于SC支路幅度缩放；与O2的概率混合alpha不同。
持续每轮禁用SC与单次O3使用同类清零操作，但时间覆盖不同。
这些benchmark设置不冒充本轮MBPP277中额外完成的局部扰动方法。

本轮未做干净/损坏运行之间的自然SC激活移植，也未做真正外部context/KV更新。
改变单点编辑所在的位置不等于第二方向的“保持候选身份、把概率质量从i搬到j”。
本表只分类snapshot14004156中的第一方向数据，其他新增实验应单独登记。
